    Default is the layout drawn for every device of this view's types. A variant is an extra layout that replaces the default only on some devices or panels, so the same view can cope with hardware that isn't always identical. Each tab is one layout.

    • Module installed – used when the device has that module, e.g. a switch with an uplink card adds the card's ports. Pick the module type and lay out the extra ports.
    • Front side / Rear side – patch panels are drawn as two strips, front ports and rear ports. Each strip uses its own variant (the default is used if one is missing).
    • Custom selector – for advanced cases: any CSS selector starting with .deviceview.

    Most switches only need the default. When several layouts match a device, the most specific one wins (a module or side variant beats the default).
